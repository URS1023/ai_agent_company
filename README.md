# 制造业 Agent 平台前端预览

直接打开根目录的 `index.html`，或运行 `npm start` 后访问 http://127.0.0.1:4173 。无需安装第三方依赖。

本次按用户最新要求只发布新增前端和项目文档，不包含原项目源码和设备数据包。

## 界面范围

- 9个主导航、17个功能模块、45个栏目入口。
- 设备质检：对象与工况选择、指标判定、明细、复核和检查记录。
- 预测性维护：运行指标、同工况趋势、维护依据和检查处理。
- 产品质检：批次与样本、检测结果、异常明细和复核。
- 知识库、文件树表、工作流画布、图谱、Agent调试、模型配置等使用各自布局。
- 数据为本地样例，尚未接入数据库、模型、Dify及Open WebUI服务。

## 文件与维护

| 路径 | 用途 |
|---|---|
| `index.html` | 内置公共组件及素材的独立预览 |
| `frontend/` | 本次新增的业务样式和交互 |
| `tools/build_preview.py` | 刷新HTML内嵌的业务样式与脚本，`npm run build` |
| `tools/serve.mjs` | 本机静态预览服务，`npm start` |
| `项目文档/README.md` | 产品、架构、开发及验收文档入口 |
| `需求梳理/` | 需求追溯、核查报告、进度与索引 |
| `screenshots/` | 实际浏览器截图及检查证据 |

运行 `npm run check` 检查脚本语法。修改 `frontend/` 后运行构建即可更新独立HTML，无需原参考项目目录。

前端复用 qknow-frontend-design 的设计方式与素材，来源及许可见 `NOTICE.md`、`licenses/qKnow-LICENSE.txt`。
