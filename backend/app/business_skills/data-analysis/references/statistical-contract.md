# 统计口径契约（data-analysis）

## 1. 范围与依据
- 统计开始前明确：统计对象、时间范围、指标口径、单位、数据源（唯一确认或本轮选择）。
- “查询成功”的定义：`query_business_data` 或 `query_inventory_data` 返回 success 回执、真实 `queryId` 和 `data`；空数组表示本次无匹配记录，仅列出目录/发现源不算查询成功。
- 当前库存、仓库目录、物料目录优先 `query_inventory_data` 的 `inventory`、`warehouses`、`materials` 模式；需要历史区间或特殊汇总时使用 `query_business_data`，不能丢掉用户条件。
- 数据范围以回执中的 `truncated` 为准：截断结果必须标注“仅部分结果”，不得当作全量。

## 2. 只读与授权
- 一律使用当前用户可访问且本轮选择/唯一确认的数据源；工具每次执行仍逐项鉴权。
- 数据库只读：`query_business_data` 走平台只读管线（白名单 + SQL 安全校验 + 200 行上限）。
- 工具超时、断连或资源异常后停止相关访问，不自动重试、不扩大超时、不换源。

## 3. 数值规则
- 数值必须来自已确认的查询结果或历史来源，写出时间、单位、统计范围及缺失依据。
- 聚合口径：合计/均值/占比必须与查询返回一致，不自行推断未查询环节。
- 缺失字段写“待提供/待确认”，不能推成零、正常、已完成或无需处理。
- 不同物料或不同计量单位不能合计；安全库存/阈值为空不能判为正常。单位没有提供时保留未知，不自行换算。
- 示例：收入减回款仅是两项数据的差额，缺少期初应收、调整、核销时不能称应收余额；
  库存账面数量不自动等于可用库存，也不足以判断是否需要补货。

## 4. 交付
- 同一已核验统计可作为图表/文档/大屏共享依据，不为每种附件重复查询。
- 需要图表时先通过上述业务查询工具保存查询，再 `render_chart_image(query_id, ...)`；
  Excel 用 `export_query_spreadsheet(query_id,name)`，数据 PPT 用 `export_query_presentation(query_ids,title,name)`。
  同批数据使用相同查询标识，不重新抄写数字，也不把模型自编的数据数组当来源。
- 饼图/表格/PPT/Word 中的每个关键数字必须能追溯到具体查询回执。
