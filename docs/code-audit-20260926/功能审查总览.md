# 当前项目功能审查总览

审查日期：2026-09-26。依据当前工作区源码，包含开始审查时已有的未提交修改。关注实际功能、前后端调用是否接通、实现边界和用户操作故障。旧 README 和代码注释只作对照，不能代替实现证据。

## 结论

当前项目是包含数据分析、工作流、设备预警、产品质检、知识库/图谱、业务 Bot、文档与大屏、应用封装及运营管理的企业业务平台。AI 对话是其中一个入口，多个业务模块也有独立页面和直接执行接口。

主要功能均能追踪到页面、接口、业务处理和结果记录；这并不表示所有配置下都已经可正常使用。此次确认了工作流保存/正式运行、定时任务状态、对话流式输出与中断记录等具体功能故障，也发现若干模块的名称容易让人高估其实际实现范围。

## 需要替代旧说明的关键事实

1. 首页为平台工作台，聊天入口是 `/ai`；产品质检 `/quality` 与数据质量 `/analytics/quality` 不是同一个功能。
2. 当前对话主入口经过 `runtime.engine`；旧 `runtime/agent.py` 的存在和测试数量不能证明它仍负责当前主对话循环。
3. 平台工具目录、工作流可调用能力和当前对话引擎实际装载工具，是三种不同范围，不能直接等同。
4. 非结构化知识抽取、工作流 parallel、应用启动、站内通知和备份恢复均有上表列出的实际边界。
5. 项目既有只读分析，也有明确确认后的数据写回；不能用一句“业务数据只读”概括整个产品。
6. 有些旧组件已不在当前页面依赖中。例如 `AiGenerationConsole` 留有模拟进度实现，但现行大屏设计器使用 `GenerationStatusPanel`，不能把遗留组件当成当前用户看到的功能。
7. 语法、类型检查或协议模拟通过，只能证明相应层级；当前旧对话集成测试的 mock 与原生执行链已经脱节，失败原因需与业务功能缺陷分开。
