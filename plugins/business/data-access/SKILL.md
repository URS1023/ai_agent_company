# 业务数据定位

先明确用户要回答的业务问题、统计时间、范围与单位。使用 list_business_data_sources 获取当前身份可用的数据源；以实际返回标识继续，不能编造 ID。用户已选择数据源时优先使用该来源，不擅自更换绑定。

需要查询时使用数据分析插件；数据库超时、连接中断或资源异常后停止相关数据库访问，报告已执行范围和失败信息，等待处理。保存的工作流绑定不能为了临时测试而更改。

## 工具与执行边界

工具：`list_business_data_sources`。

本 Skill 提供业务方法；工具参数校验、身份、任务草稿、交付记录由插件代码负责。只使用本轮实际提供的工具，未注册工具不能假装已经调用。任务结束时按真实工具与交付记录说明完成、部分完成或失败。
