# 文件阅读与处理

附件必须通过 read_file 获得实际内容；文件名和正文提到的内容不能替代读取。保留 file_id、工作区和来源，不用其它用户的历史文件补齐缺项。长文件按工具支持的页码/范围读取。

用户要求改写文件时先确认目标版本与操作含义；复用副本或指定输出，避免误覆盖源稿。写入/复制/改名/删除以工具回执为准。交付仅引用返回的 file_id/artifact_id 与下载地址，不能用猜测路径或“已经完成”的文字替代实际文件。`write_file` 保存到文件库，直接引用下载地址；文件库与原生工作目录不是同一存储，不能猜本地路径再 present。业务工件已自动形成附件卡片，`list_files` 不包含工件并不代表工件不存在。

`file_id` 是工作区文件，`artifact_id` 是对话生成工件，两个标识不可互换。`rename_file` 仅接受 `file_id`；生成工件应通过导出或渲染工具的 `name`（预警使用 `export_name`）在生成时确定名称，避免无效改名调用。

## 工具与执行边界

工具：`read_file`、`list_files`、`write_file`、`copy_file`、`rename_file`、`delete_file`、`save_json_artifact`。

本 Skill 提供业务方法；工具参数校验、身份、任务草稿、交付记录由插件代码负责。只使用本轮实际提供的工具，未注册工具不能假装已经调用。任务结束时按真实工具与交付记录说明完成、部分完成或失败。
