# PPT 生成项目拆解与模板系统落地

## 两个项目的定位

### AiPPT

AiPPT 是一个轻量浏览器端演示文稿工作台。公开部分重点在 PPTX 结构解析、JSON 中间层、SVG/Canvas 预览、元素编辑、缩略图、SSE 进度和 PPTX 回写。

值得借鉴的产品能力：

- 主题 → 大纲 → 模板 → 分页生成的渐进式流程；
- PPTX → JSON 的结构化中间层；
- 文字、图片、形状、表格、图表、动画等统一元素模型；
- 生成过程中逐页预览，而不是等待整份文件结束；
- 上传模板后可以检查、编辑并重新导出。

边界：AiPPT 使用 GPLv3，且 AI 内容生成服务端未开源。当前平台没有复制其 GPL 源码、内置 API Key 或外部服务调用，仅以其产品交互和中间层思想作为设计参考。

### ppt-master

ppt-master 是 MIT 许可的完整演示文稿方法体系，覆盖内容策略、品牌/风格/布局/场景模板、母版与占位槽、SVG/PPTX 双向处理、动画、音频和交付质检。

最值得抽取的工程原则：

- 将模板拆成 Brand、Style、Layout、Deck 四层，而不是只保存颜色；
- 为页面定义 cover、agenda、section、content、data、closing 等语义角色；
- 内容先匹配页面结构，再填充；不按源模板页序机械替换；
- 每个占位槽同时包含用途、几何范围和容量约束；
- 结论先行，每页只承担一个叙事任务；
- 内容过密时拆页，不依赖缩小字号或裁掉内容；
- 输出前检查边界、溢出、图表、表格、字体、母版和 Open XML 兼容性。


## 内置模板升级

当前目录固定为 20 套客户可选的高级模板：象牙高管、午夜数据、极光玻璃、瑞士信号、编辑部红、工程蓝图、纸张策略、现代水墨、孟菲斯创意、黑白粗野、柔和 SaaS、赛博霓虹、ESG 自然、黑金典藏、政务红、医疗洁净、学术酒红、工业橙、影像叙事和数据新闻。

每套模板都拥有独立的封面构图、背景纹理、页眉结构、卡片轮廓、指标表达、对比形式和时间线，不以换色充当新模板。20 份示例使用 20 个不同业务主题和 20 条唯一的 12 页正文编排；生成脚本为每套模板创建一份 14 页完整示例，并按各自叙事抽取最有代表性的四页组成真实 2×2 预览。选择器底部可直接下载完整示例 PPTX。

模板选择器使用四列桌面模板库，并提供关键词搜索、用途分类、内置/客户来源筛选、实时结果数量和固定选择栏；在平板与手机上依次降为两列和单列。上传客户 PPTX 时同样缓存真实首屏渲染图。

页数支持自动决定或精确选择 3–30、35、40、50 页，定义为包含封面和结束页的总页数。选择明确页数后，运行上下文、模型提示、工具参数和最终 PPTX 页数会逐层核对。正文页要求同时包含结论、证据和解释；普通页、卡片、指标、对比、时间线和图表均有内容完整性约束，避免只有标题或大面积无信息留白。

## 客户 PPTX 模板分析

上传客户模板后会生成 `presentation_template_profile.v1` 侧车清单，记录：

- 页面比例、样例页数、母版数和布局数；
- 可用布局名称、页面角色和占位符类型；
- 高频字体、颜色与真实预览色；
- 图片、表格和图表数量；
- 内容密度与推荐布局族。

渲染时优先使用客户 PPTX 的原始母版和布局；没有可用原生布局时，才基于真实字体和配色生成兼容页面。

## 资源组件与样式保留策略

### 应作为产品能力长期保留

| 类型 | 保留内容 | 落地方式 |
|---|---|---|
| 沟通方法 | consulting-decision、operating-review、solution-proposal、technical-deepdive、workshop-teaching、narrative-keynote | 作为模板的表达策略和故事线规则，不复制原始项目工作流 |
| 通用布局 | presentation_core、report_core、editorial_bleed 中的页面角色 | 转为当前引擎的 statement、metrics、comparison、timeline、chart、table 等原生布局 |
| 画布适配 | 16:9 与 4:3 | 保留；社交竖版和小红书画布留作后续独立输出类型，不混入普通 PPT |
| 图表选型 | 柱状、横向条形、折线、面积、饼图、环形图，以及图表适用/禁用条件 | 使用原生 PowerPoint 图表和选型规则，不复制 SVG 示例图 |
| 客户资源 | 客户上传的 PPTX、母版、布局、字体、配色、Logo 与合法品牌素材 | 按 Workspace 保存，保留来源与结构画像，不写进全局内置模板 |
| 质检能力 | 越界、空白页、Open XML、关系、字体、外链媒体和严格渲染检查 | 纳入测试和交付门槛 |

### 只在用户明确要求时启用

- `photo-editorial`：适合有高质量照片的品牌发布或案例故事；无图片时不启用。
- `dark-tech`：适合技术发布、网络安全和基础设施主题；不作为普通商务默认样式。
- `swiss-minimal`：适合严谨观点和研究汇报，可作为极简模板的视觉参考。
- `data-journalism`：适合证据密集的数据叙事，但必须有真实数据和来源。
- `soft-rounded`：适合培训、消费和内部沟通；正式投标与高管决策不默认使用。
- `glassmorphism`、`memphis`、`brutalist`、`pixel-art`、`vintage-poster`、`zine`、`chalkboard`、`paper-cut`、`ink-wash`：属于强风格资源，仅在用户明确选择时使用，不能自动套到企业材料。
- 动画、转场、音频和旁白：只在交付场景确实需要时启用，静态商务 PPT 默认不增加。

### 完整保留但默认隔离的资源

- AiPPT 的 GPLv3 JavaScript、外部接口流程和演示资源完整保留在原始参考库；示例硬编码 Key 不进入配置，也不会自动调用外部接口；
- ppt-master 的完整 12,027 个图标及其第三方许可声明保留为懒加载图库；
- Simple Icons 品牌 Logo 全集保留，但每次使用都要求商标审查；
- 中国电信、中国电建、华为、咨询公司等品牌专属 Logo 和模板资产保留为受限品牌资源；
- 第三方赞助商图片、宣传 GIF、演示截图和 AI 图片对比样例保留为预览/研究材料；
- 186 个音频样例、旁白、动画和视频流水线保留为可选交付资源；
- SVG 原型与 Python 原生布局可以同时保留，但生产生成默认使用原生布局；SVG 仅在明确选择相应模板或需要忠实复刻时启用。

这些资源通过 `presentation_resource_inventory.v1` 登记，采用“原始源完整保留 + 运行时懒加载”模式。资源清单 API：

```text
GET /api/presentation-templates/resources
GET /api/presentation-templates/resources/icons?library=tabler-outline&query=chart
```

外部服务默认 `enabled=false`，启用时必须使用 Secret Reference，不能从参考项目读取示例密钥。

### 图标保留边界

如后续确需图标，只按项目复制少量实际使用的图标，不整库打包：

1. 每份 PPT 只选择一种通用图标风格；
2. 优先选择 Tabler Outline 或 Phosphor Duotone 的少量图标；
3. 同步保留对应 MIT 版权声明；
4. CHUNK Icons 需要保留 CC BY 4.0 署名；
5. Simple Icons 只用于真实品牌，并在使用前检查商标规范；
6. 图标无法增加信息时不使用，让数字、图表或文字承担表达。

当前实现遵循以上策略：所有原始品牌、样例、图标、音频和适配脚本继续保留，并已建立可审计清单；默认生成链路只加载当前任务明确选择的少量资源。

## 许可与来源边界

- AiPPT：GPLv3；仅借鉴产品思想，没有复制代码。
- ppt-master：MIT；采用其公开的模板分层、页面角色、内容适配和质检理念，当前渲染器为本项目独立实现。
- 品牌模板和商标资产不会默认复制到平台内置模板中。

## 验证

运行：

```powershell
python backend/smoke_presentation_templates.py
```

测试会用复杂投标决策案例遍历全部 20 个模板，并检查 16:9、4:3、图表、表格、自动分页、形状边界、预览唯一性和客户模板结构分析。`npm run ui:check` 还会验证模板搜索、分类、来源、完整示例下载、客户上传，以及桌面/移动端布局。完整示例目录位于：

```text
examples/presentation-templates/
```
